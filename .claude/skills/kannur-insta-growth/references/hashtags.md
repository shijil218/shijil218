# Hashtag sets

Use 5 to 10 per post: about half local, half service-specific, plus one or two broad tags. Rotate sets so every post isn't identical. Tags with millions of posts bury a small shop's post fast; local and niche tags give it a chance to be seen by people nearby.

## Local (always include 2–4)
#kannur #kannurdiaries #kannurcity #kannurkerala #kerala #keralagram #thalassery #payyanur #taliparamba #iritty #mattannur #chakkarakal #mouwanchery #anjarakandy #kannurbusiness #kannurshop

(Only use town tags like #thalassery or #payyanur if the shop actually serves those areas.)

## Service-specific
- Laptop: #laptoprepair #laptopservice #laptoprepairkannur #laptopscreenreplacement #laptopcleaning
- Desktop/PC: #pcrepair #computerrepair #computerservice #pcbuild #gamingpc
- Data: #datarecovery #harddiskrecovery #backup
- Upgrades: #ssdupgrade #ramupgrade #laptopupgrade
- Tips: #techtips #laptoptips #computertips #malayalamtechtips

## Broad (0–2)
#techmalayalam #malayalam #reelsinstagram #repair #satisfying

## Brand tag
Create one and use it on every post, e.g. #kannurcomputers, so all the shop's work is in one place and customers can use it too.

## Before using a tag
Remind the user to tap the tag in Instagram once to check it's active and not full of spam or unrelated content; tag use shifts over time.
